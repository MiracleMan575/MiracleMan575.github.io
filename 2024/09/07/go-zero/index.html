1 安装

需要安装goctl，可以直接访问go-zero的官方 github

当然此外还需要安装proto相关依赖，

protoc >= 3.13.0 ， 如果没安装请先安装 https://github.com/protocolbuffers/protobuf，下载解压到$GOPATH/bin下即可，前提是$GOPATH/bin已经加入$PATH中

对于goctl大于1.3.3版本，可以使用env命令直接安装

生成代码目录

生成后有三个文件，分别是api、etc、internal以及一个user.go

主要操作顺序为

  • 1.读取etc/xx.yaml文件，将配置映射到声明的c config.Config上
  • 2.调用svc下的serviceContext，将配置文件中的依赖放到svc，后续直接调用
  • 3.启动一个个server，defer延时关闭
  • 4.handler通过register注册路由，主要通过router方法，将每个路由对应到某个Handler上，对于任意Handler几乎都传入了svc，解析请求参数交给logic，这里就是写具体业务处理方法的地方了。

关于Model

注意在findByMobile中，查询Mobilekey，如果有回get到value，比如是id=1，那么他会再在缓存中查询id=1得到真正返回值；没有缓存时就去数据库进行查询了。

关于Middleware

api文件service加middleware，不支持单个增加，使用apigen生成后会发现internal内多了一个middleware的文件夹，同时router中多出rest.Middleware，需要在serviceContext引入middleware

也可以在router中的每个路由中加middleware但是重新生成api就会被冲掉，不推荐。

全局也可以加middleware，并需要在user.go程序入口处引入

注意当全局和局部中间件同时存在，顺序为全局-局部-逻辑-局部结束-全局结束。
