2 切片

2.1 切片的定义

  • 切片是数组的引用，属于引用类型，即引用传递
  • 切片由元素、长度、容量组成，容量可动态变化
  • 使用类数组，但切片长度可变化，可理解为动态数组
  • 定义语法 var a []int
  • 前闭后开：假设有一数组{1,2,3,4} 若使用 slice : = intArr[1:3]  得到的切片为{2，3}

2.2 切片的使用

切片初始化

  • 切片引用数组

  • 定义切片直接指定具体数据类make

2.3 使用说明

  • 未引用到仍会越界
  • 切片可以继续切片（套娃）
  • 使用append可以对对切片进行追加元素
append底层分析
  1. 检查元素数量：首先检查是否有元素需要添加。如果没有，直接返回原切片。
  2. 判断容量是否足够：如果待添加的元素数量加上当前切片的长度超过了切片的容量，那么就需要扩容。
  3. 计算新容量：见2.4扩容机制
  4. 分配新数组并复制数据：分配一个新的底层数组，并将旧切片中的所有数据复制到新数组中。
  5. 添加元素并更新长度：将新元素添加到新数组的末尾，并更新切片的长度。
  6. 返回新切片：返回一个引用新数组的切片，其长度为原始长度加上新添加的元素数量。
copy内置函数

copy(slice1,slice2) // 将2拷贝给1

若slice1长度为3，slice2长度为10，则会将slice2的前三位拷贝给slice1对应位置

copy前后slice1和2都数据独立，没有引用关系

2.4 slice扩容机制

1.7版本扩容机制

如果当前容量小于1024，则判断所需容量是否大于原来容量2倍，如果大于，当前容量加上所需容量；否则当前容量乘2。

如果当前容量大于1024，则每次按照1.25倍速度递增容量，也就是每次加上cap/4。

1.18版本扩容机制

Go1.18不再以1024为临界点，而是设定了一个值为256的 threshold，以256为临界点；超过256，不再是每次扩容1/4，而是每次增加（旧容量+3*256）/4；

  1. 当新切片需要的容量cap大于两倍扩容的容量，则直接按照新切片需要的容量扩容；
  2. 当原 slice 容量 < threshold 的时候，新 slice 容量变成原来的 2 倍；
  3. 当原 slice 容量 > threshold，进入一个循环，每次容量增加（旧容量+3*threshold）/4。

string 和slice

由于string底层是byte数组，所以string可以进行切片处理，以此可以修改string。

string不可变，所以对于 str[0] = '1' 会报错，若想修改字符串，则需将string转为byte切片或rune切片
