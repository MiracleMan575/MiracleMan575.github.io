前面几个章节我们在源码中不少见到 atomic 原子操作的身影。接下来我们就掀开他的面纱。

什么是原子操作？

原子操作是指在计算机科学中 不可分割 的一系列操作。意味着这些操作要么全部执行完成，要么完全不执行；不会出现部分执行的情况。原子操作通常用于多线程编程环境，以确保数据的一致性和完整性。

Go 语言的 sync/atomic 包提供的原子操作主要依赖于底层硬件的支持。现代CPU提供了特定的指令来执行原子操作，比如 CAS(Compare-And-Swap)、 XCHG(Exchange) 等，这些指令保证了在多核或多线程环境中对共享数据的操作是原子的，即不可分割的。

使用

使用场景

不需要其他并发原语复杂的逻辑，可以使用原子操作来实现并发控制。

基本方法

atomic 支持 int32、 int64、 uint32、 uint64、 uintptr、 Pointer 提供了分别提供了 AddXXX、 CompareAndSwapXXX、 SwapXXX、 LoadXXX、 StoreXXX 等方法。

我们着重看一种就可以了， atomic 操作的对象是一个地址，需要把可寻址的变量的地址作为参数传递给方法，而不是把变量的值传递给方法。

Add

Add 方法就是给第一个参数地址中的值增加一个 delta 值。对于无符号值可以使用计算机补码规则将减法变成加法。

CAS

比较当前 addr 地址里的值是不是 old，如果不等于 old，就返回 false；如果等于 old，就把此地址的值替换成 new 值，返回 true。

Swap

不需要比较旧值，只是比较粗暴地替换，返回旧值。

Load

取出 addr 地址中的值。

Store

Store 方法会把一个值存入到指定的 addr 地址中
