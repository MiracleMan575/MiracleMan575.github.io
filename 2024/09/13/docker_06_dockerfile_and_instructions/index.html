什么是Dockerfile?

Dockerfile 是一个文本文件，它包含了用户可以在命令行上调用的命令来创建一个 Docker 镜像。Docker 可以读取 Dockerfile 中的指令，并根据这些指令自动构建镜像。通过 Dockerfile，你可以自动化地创建一致的环境，确保在任何地方都可以复现相同的运行时环境。

一个Dockerfile可能由以下指令组成：

  1. 基础镜像 ( FROM): 指定新镜像是基于哪个基础镜像构建的。
  2. 元数据标签 ( LABEL): 提供有关镜像的元数据信息。
  3. 运行命令 ( RUN): 在当前镜像之上执行命令，每个 RUN 指令都会创建一个新的层。
  4. 添加文件/目录 ( ADD 或 COPY): 将文件或目录从构建上下文复制到镜像中。
  5. 设置工作目录 ( WORKDIR): 设置容器启动后的默认工作目录。
  6. 设置环境变量 ( ENV): 设置环境变量。
  7. 暴露端口 ( EXPOSE): 声明容器运行时监听的网络端口。
  8. 定义默认命令 ( CMD): 定义容器启动时默认执行的命令。
  9. 覆盖默认命令 ( ENTRYPOINT): 与 CMD 类似，但允许将参数传递给 ENTRYPOINT。
  10. 卷挂载点 ( VOLUME): 创建一个可以从宿主机或其他容器挂载的挂载点。
  11. 指定健康检查 ( HEALTHCHECK): 用于检测容器是否正常运行。
  12. 其他指令: 如 USER, ONBUILD 等，用于更复杂的场景。

其中FROM是必须的，其他都是可选的。
